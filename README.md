## 🚀 Featured Projects

<details>
<summary><b>☁️ Azure Multi-OS VM Infrastructure with Terraform</b></summary>
<br/>

Modular Infrastructure-as-Code solution provisioning both Linux and Windows Virtual Machines on Microsoft Azure — covering VNets, subnets, NSGs, NICs, and public IPs across **10 reusable Terraform modules**. Integrates Azure Key Vault for dynamic credential retrieval, eliminating hardcoded secrets from configuration and state files. Uses a data-driven, map-based variable design so multiple resources of the same type can be deployed from a single reusable object definition.

| Category | Details |
|---|---|
| **Stack** | Terraform, Microsoft Azure, Azure Key Vault, Azure CLI |
| **Scale** | 10 reusable modules across VNets, subnets, NSGs, NICs & public IPs |
| **Performance** | Reproducible provisioning via full `init → plan → apply → destroy` workflow |
| **Security** | Secrets fetched at runtime via Key Vault — zero hardcoded credentials |
| **Impact** | Map-based variable design cut duplication across environment configs |
| **Repository** | [View on GitHub](https://github.com/adithyavenkatkumar?tab=repositories) |
