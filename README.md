## Featured Project

### Azure Multi-OS VM Infrastructure with Terraform

A modular Infrastructure-as-Code solution for provisioning Linux and Windows virtual machines on Microsoft Azure, built around reusable, environment-agnostic Terraform modules.

| Aspect | Details |
|---|---|
| **Stack** | Terraform, Microsoft Azure, Azure Key Vault, Azure CLI |
| **Scope** | 10 reusable modules covering VNets, subnets, NSGs, NICs, and public IPs |
| **Security** | Credentials retrieved dynamically via Azure Key Vault; no hardcoded secrets |
| **Design** | Data-driven, map-based variable configuration for multi-resource deployment |
| **Workflow** | Full `init → plan → apply → destroy` lifecycle with Azure CLI authentication |
| **Repository** | [View on GitHub](https://github.com/adithyavenkatkumar?tab=repositories) |

**Key contributions:**
- Designed modular Terraform architecture for cross-platform (Linux/Windows) provisioning
- Integrated Azure Key Vault to eliminate hardcoded credentials from configuration and state
- Implemented map-based variable design to reduce duplication across environments
- Authored complete deployment documentation for reproducible provisioning

## Approach to Infrastructure

I treat security and reliability as integral parts of the infrastructure lifecycle rather than a final step:

**Plan → Code → Build → Secure → Test → Deploy → Monitor → Improve**

Core principles I apply:
- Secure handling of credentials and secrets
- Infrastructure as Code for reproducibility
- Automation over manual configuration
- Continuous monitoring and observability
- Security integrated throughout, not appended at the end
